# 上财选课助手(半自动版) · 使用说明

> 定位:提前录入心愿单 → 在你**自己的登录会话**里定时监测空位 → 发现空位就**声音+系统通知+高亮**提醒,由你本人去点"选课"确认。
> 不自动提交选课、不保存/上传任何人的账号密码、无服务器、纯本地。
> 请遵守学校通知中关于选课系统的要求;若官方明确禁止脚本监测,请停止使用。

## 文件清单

| 文件 | 作用 |
|---|---|
| `index.html` | 心愿单管理(本地网页,双击用浏览器打开):添加/编辑/排序课程、导出导入 JSON、复制课程序号清单 |
| `xuanke-monitor.user.js` | Tampermonkey 用户脚本:浮动面板 + 定时监测 + 提醒(目前为骨架,已可加载运行) |
| `README.md` | 本说明 |

两处共用同一份 JSON 格式:

```json
{ "version":1, "items":[ { "id":"...", "name":"羽毛球 I", "code":"SPT000123",
  "prio":1, "type":"体育", "status":"main", "time":"", "note":"" } ] }
```

- `status`:`main` = 主选(被监测)/ `backup` = 备选(不自动盯,作为抢不到时的候选,面板里随时可"去选课"查看)
- 数据分别存在「本网页的浏览器 localStorage」和「Tampermonkey 的独立存储」里,互不干扰,靠 JSON 搬运。

## 第一步:录心愿单

1. 双击打开 `index.html`(推荐 Chrome / Edge,无需联网);
2. 添加课程:**课程名称 + 课程序号**(选课系统里每个班次有唯一序号,开选后在系统搜索框能查到;现在先填占位,开选后改)、优先级、类型、志愿(主选/备选)、时间备注;
3. 用 ↑↓ 调整顺序、随时编辑删除;完成后点「复制课程序号清单」可把序号粘到选课系统里快速查状态。

## 第二步:安装监测脚本

1. 浏览器安装 **Tampermonkey**(Chrome 应用商店/Edge 加载项搜索即可);
2. 点击 Tampermonkey 图标 → 管理面板 → 右上"+"/新建脚本;
3. 把 `xuanke-monitor.user.js` 的全部内容粘贴进去,保存(Ctrl+S),确认脚本已启用;
4. 打开 https://portal.sufe.edu.cn 任意页(或登录后打开的选课页面),右下角会出现红色 **"🎯 选课助手"** 按钮。

## 第三步:导入清单并开始监测

1. 在 `index.html` 里点「导出 JSON」→ 把内容复制;
2. 在任意上财网页点开"选课助手"面板 → 粘贴到顶部输入框 → 点「导入」;
3. 建议间隔选 **15–30 秒**(默认 20,勿用 5 秒以下高频,避免给学校服务器造成压力、也降低风控风险);
4. 点「开始监测」:首次会请求浏览器通知权限,请允许;
5. 之后把浏览器标签留在选课页面挂着(页面最小化也可以,浏览器别关),发现空位会响铃+系统通知+列表变绿,点该课程右侧「去选课」进入操作,由你手动提交选课;
6. 不需要的课点「忽略」;抢到主选后点「停止」。

> 现在跑的是"占位版":监测循环与提醒已经能演示,**但查询空位需要对接真实选课页面**(见下)。

## 第二阶段:对接真实选课系统(需要你帮忙采集一次信息)

选课开放后,请用你的账号登录门户 → 打开「选课」应用,然后按下面清单把信息发给我,我会填好脚本里的对接层:

1. **选课页面的网址**(浏览器地址栏完整 URL);
2. **打开 F12 → Network(网络)面板**,刷新/操作一次"查询可开课程或余量",找到名称像 `course`/`select`/`remain`/`choose`/`query` 的请求,发我:
   - 请求地址(Request URL)、方法(GET/POST);
   - 请求参数(Payload/Query String);
   - 返回内容(Response,JSON 或 HTML 片段均可,去掉隐私字段也没关系);
3. 课程列表中"课程序号、余量、选课按钮"在页面上长什么样(截图或描述);
4. 确认是否有其他学院/专业规则差异(可只先覆盖你自己的课)。

拿到这些后,我把它填进 `xuanke-monitor.user.js` 顶部「对接层」的两个 TODO 函数(查询余量、打开课程页),你更新脚本即可使用完整功能。

## 常见问题

- **声音/通知没响?** 首次「开始监测」时允许浏览器通知权限;页面最小化时 Chrome 可能节流定时器,建议把标签页留在前台或使用系统通知(经 GM_notification)。
- **自动选课?** 不做。原因:①校规与风控风险;②学校名额随机释放,脚本顶不掉"运气+手速";③真自动抢出问题(冲突、退课冻结)没有后悔药。半自动只差最后一下点击,安全性完全不同。
- **能分享给同学吗?** 可以:把本文件夹发给他们各自安装即可(每个人的登录会话只在自己的浏览器里,不经过你)。不要把它改成"收集别人账号"的服务版——那是违规且违法的。
